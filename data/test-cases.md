# Lucky Growth Agent 测试用例集

> 本文件包含 20 条标准化测试用例，覆盖六大意图类型、四个用户生命周期阶段、多种场景组合。
> 用于评估 Agent 的意图识别准确率、推荐质量、文案质量和整体表现。

---

## 测试用例说明

### 评估维度

| 维度 | 评估方法 | 满分 |
|------|----------|------|
| 意图识别准确率 | 人工标注的意图类型 vs Agent 输出 | 30分 |
| 生命周期判断准确率 | 人工标注的阶段 vs Agent 输出 | 10分 |
| 推荐产品合理性 | 产品是否匹配意图和偏好 | 20分 |
| 优惠策略合理性 | 优惠力度是否匹配用户阶段 | 10分 |
| 文案质量 | 场景化、有温度、行动号召明确 | 15分 |
| 输出格式规范性 | 是否符合结构化输出要求 | 10分 |
| 置信度判断合理性 | 置信度等级是否准确 | 5分 |
| **总分** | | **100分** |

### 测试方法

1. 逐条输入用户数据，记录 Agent 的完整输出
2. 按照评估维度逐项打分
3. 计算总分和各维度平均分
4. 识别低分案例，分析原因，用于迭代优化
