# Agent 测试结果样例集

> 本文件展示 Lucky Growth Agent 在典型场景下的实际输出样例。
> 所有样例基于 V3 版本系统提示词，使用通义千问 Max 模型运行。
> 格式为：用户输入 → Agent 思考过程 → Agent 结构化输出。

---

## 样例 01：高置信度 - 习惯复购（黑金会员周一早晨）

### 用户输入
```
用户ID：U001（王磊）
时间：周一 8:45
天气：晴 21°C
位置：公司楼下（距门店200米）
历史偏好：美式大杯（85%）、拿铁大杯（15%）
最近消费：
- 昨天 8:50 美式大杯
- 前天 8:48 美式大杯
- 大前天 8:52 美式大杯
月消费频次：22杯
累计消费：3,200元
会员等级：黑金会员
优惠券使用率：8%
```

### Agent 思考过程

```
Thought: 让我分析这个用户的信号：
1. 时间信号：周一8:45，工作日早晨，典型通勤时段 → 提神/习惯
2. 位置信号：公司楼下，距门店200米 → 到店自取场景
3. 行为信号：连续3天8:50左右点美式大杯，月消费22杯 → 极强习惯复购
4. 会员等级：黑金会员，累计3200元 → 成熟用户
5. 偏好一致性：85%美式大杯 → 偏好极其明确
6. 优惠券使用率仅8% → 价格不敏感，不需要大额券

多维度信号高度一致：工作日早晨+公司楼下+连续3天同一时段同一产品+高频用户。
意图判断：习惯复购（置信度92%）。
生命周期：成熟用户。
推荐策略：老样子美式大杯，黑金会员8.5折，一键复购，到店自取。
文案要简洁直接，不打扰。
```

### Agent 结构化输出

---

**【意图识别结果】**

- **意图类型**：习惯复购
- **置信度**：92%（高置信度）
- **生命周期阶段**：成熟用户（黑金会员）
- **关键判断依据**：
  1. 工作日早晨8:45，与用户历史下单时段（8:50）高度吻合
  2. 位置在公司楼下门店200米，符合日常到店自取模式
  3. 连续3天同一时段点美式大杯，行为一致性极高
  4. 月消费22杯，黑金会员，属于高频成熟用户
  5. 美式大杯占比85%，偏好极其明确

---

**【推荐策略】**

- **推荐产品**：美式 大杯（热/冰根据当日气温推荐，21°C推荐热饮）
- **推荐理由**：这是王磊的"老样子"——连续3个工作日早晨8:50的固定选择，偏好占比85%。周一早晨通勤路上，到店自取，无需决策成本。
- **优惠方案**：黑金会员专享价 8.5折（折后约13.6元），无需额外发券
- **触达渠道**：APP首页弹窗 + 手机推送
- **执行时机**：立即推送（用户已在门店附近）
- **营销文案**：
  > 周一早，老样子？大杯美式已为你备好，到店即取。

---

**【执行建议】**

- **执行方式**：高置信度，可自主执行
- **操作步骤**：
  1. APP首页弹出"一键再来一单"卡片，默认美式大杯
  2. 推送通知："老样子已备好，点击一键下单"
  3. 用户点击后直接进入支付页，无需选品
  4. 门店提前备餐（基于用户历史到店时间预估）
- **预期效果**：点击率≥35%，转化率≥80%（基于历史一键复购数据）

---

**【反思记录】**

- **关键假设**：用户今天仍会走同一路线、在同一时段到店
- **可能改进点**：如果今天用户未在9:00前下单，可在9:15推送一次温和提醒；如果用户连续2天未点美式，需重新评估偏好是否变化
- **需收集的反馈数据**：本次推送是否点击、是否下单、到店时间、是否有修改订单

## 样例 02：中置信度 - 冲突信号（冰饮偏好遇大雨天）

### 用户输入
```
用户ID：U010（对应画像中雨天场景）
时间：周三 14:00
天气：大雨 15°C
位置：公司
历史偏好：冰美式（40%）、冰橙C美式（30%）、冰拿铁（20%）、其他（10%）
最近消费：上周 冰美式
月消费频次：7杯
累计消费：450元
会员等级：银卡会员
```

### Agent 思考过程

```
Thought: 分析信号：
1. 时间：周三14:00，下午时段 → 可能是下午茶/放松
2. 天气：大雨15°C，温度较低 → 热饮需求上升
3. 位置：公司 → 工作日下午
4. 历史偏好：100%冰饮（冰美式+冰橙C+冰拿铁）→ 强烈冰饮偏好
5. 月消费7杯 → 成长用户
6. 银卡会员 → 有一定忠诚度

冲突点：用户历史偏好全部是冰饮，但今天大雨15°C，天气信号强烈指向热饮。
这是一个典型的冲突信号场景。

意图判断：下午时段+公司，可能是提神（下午犯困）或放松（下午茶）。
但天气冲突使得推荐存在不确定性。
置信度：68%（中置信度）——信号有冲突，不应强行推荐。

策略：提供两个选项，尊重用户习惯的同时给出天气适配建议。
- 选项1：老样子冰美式（尊重习惯）
- 选项2：热拿铁/热摩卡（天气适配）
优惠：雨天暖心特惠。
建议人工审核后执行。
```

### Agent 结构化输出

---

**【意图识别结果】**

- **意图类型**：提神刚需 / 放松享受（下午场景，存在混合意图）
- **置信度**：68%（中置信度）
- **生命周期阶段**：成长用户（月消费7杯，银卡会员）
- **关键判断依据**：
  1. 周三下午14:00，工作日下午，可能是提神或下午茶
  2. 大雨15°C，天气信号指向热饮和温暖需求
  3. 但用户历史偏好100%为冰饮，习惯力量强
  4. 位置在公司，非社交场景
  5. 信号存在冲突（天气vs习惯），降低置信度

---

**【推荐策略】**

由于存在信号冲突，提供两个候选方案：

**候选方案A（尊重习惯）**：
- **推荐产品**：冰美式 大杯
- **推荐理由**：老样子，用户最常点的产品
- **优惠方案**：银卡会员价9.5折
- **文案**：
  > 下午好，老样子冰美式已备好，雨天也能保持清醒。

**候选方案B（天气适配，推荐）**：
- **推荐产品**：热拿铁 大杯（或热焦糖玛奇朵）
- **推荐理由**：大雨天15°C，一杯热拿铁暖身更舒适。拿铁奶香浓郁，适合下午慢慢喝
- **优惠方案**：雨天暖心特惠 - 热饮立减3元
- **文案**：
  > 雨天真冷。老样子冰美式随时能点，但今天要不要试试热拿铁暖暖身子？

**推荐选择**：建议方案B，但保留方案A让用户选择

---

**【执行建议】**

- **执行方式**：中置信度，建议人工审核后执行
- **操作步骤**：
  1. APP推送消息，采用方案B文案（天气共情+提供选择）
  2. 点击后进入菜单页，默认展示热拿铁，但保留"冰美式"快捷入口
  3. 不强行改变用户习惯，让用户自主选择
- **触达渠道**：APP推送
- **执行时机**：立即推送（下午时段正是咖啡消费时间）

---

**【反思记录】**

- **关键假设**：用户可能因为天气改变冰饮习惯，但不确定
- **可能改进点**：观察用户最终选择冰饮还是热饮，如果选择热饮，后续雨天可更主动推荐热饮；如果坚持冰饮，后续雨天不再推荐热饮
- **需收集的反馈数据**：点击了哪个选项、最终下单产品、是否使用了雨天特惠

## 样例 03：低置信度 - 新用户冷启动

### 用户输入
```
用户ID：U007（周小桐）
时间：周二 12:00
天气：未知
位置：未知
历史偏好：无（注册2天，未消费）
最近消费：无
月消费频次：0杯
累计消费：0元
会员等级：小蓝豆会员
来源：朋友圈广告
```

### Agent 思考过程

```
Thought: 分析信号：
1. 新注册用户，2天，0消费 → 新用户阶段
2. 无历史偏好、无消费记录 → 无法判断口味
3. 天气未知、位置未知 → 缺少场景信号
4. 来源是朋友圈广告"新客首杯1.8折" → 价格可能是敏感因素
5. 唯一行为：注册当天浏览菜单2分钟，未下单 → 有兴趣但决策困难

信息严重不足，无法确定意图。
置信度：30%（低置信度）。

策略：
- 不做确定性推荐（不能瞎猜）
- 通过交互获取偏好信息
- 提供低门槛首单优惠，降低决策成本
- 给出2-3个"大多数人第一杯会选"的经典选项，作为参考而非推荐
- 文案友好引导，不催促
```

### Agent 结构化输出

---

**【意图识别结果】**

- **意图类型**：无法确定（信息不足）
- **置信度**：30%（低置信度）
- **生命周期阶段**：新用户（注册2天，0消费）
- **关键判断依据**：
  1. 无任何消费记录和偏好数据
  2. 天气、位置等场景信号缺失
  3. 仅有的行为是注册当天浏览菜单2分钟
  4. 无法判断用户的口味偏好和消费场景

---

**【推荐策略】**

由于信息不足，不做确定性产品推荐，改为引导式交互：

- **策略方向**：低门槛首单体验 + 偏好引导
- **首单优惠**：新客专享 1.8折（首杯低至约3元），降低尝试门槛
- **参考选项**（非确定性推荐，供新用户参考）：
  - 不知道喝什么？大多数人的第一杯是 **拿铁**（奶香丝滑，接受度最高）
  - 喜欢清爽口感？试试 **美式**（纯粹咖啡香，零糖零脂）
  - 想喝网红爆款？**生椰拿铁**（累计销量21亿杯，椰香丝滑）
- **交互引导**：
  > 你平时更喜欢哪种口味？
  > A. 奶香丝滑（拿铁类）
  > B. 清爽纯粹（美式类）
  > C. 甜香浓郁（特调类）
  > D. 不太喝咖啡，想喝茶

---

**【执行建议】**

- **执行方式**：低置信度，不自动执行推荐，转交互引导
- **操作步骤**：
  1. APP内弹出新客欢迎卡片，展示1.8折首单优惠
  2. 提供口味偏好选择题（A/B/C/D），用户选择后再做精准推荐
  3. 同时展示3个经典选项的快捷下单入口（拿铁/美式/生椰拿铁）
  4. 引导加入企业微信社群，获取更多新客福利
- **触达渠道**：APP内消息（不主动推送，避免打扰）
- **执行时机**：用户下次打开APP时展示

---

**【反思记录】**

- **关键假设**：用户对价格有一定敏感度（被1.8折广告吸引），但不确定
- **可能改进点**：用户选择口味偏好后，立即生成个性化推荐；如果用户24小时内未响应，可推送一次温和的首单提醒
- **需收集的反馈数据**：用户是否选择了口味偏好、浏览了哪些产品、是否使用首单券下单

## 样例 04：流失用户召回

### 用户输入
```
用户ID：U008（孙浩）
时间：周四 16:00
天气：晴 24°C
位置：家
历史偏好：生椰拿铁（50%）、橙C美式（30%）、其他（20%）
最近消费：45天前 生椰拿铁
月消费频次：历史月均6杯，近1个月0杯
累计消费：850元
会员等级：金卡（已降级为银卡）
历史复购周期：5-7天
```

### Agent 思考过程

```
Thought: 分析信号：
1. 45天未消费，历史复购周期5-7天 → 严重偏离，已流失
2. 金卡降级为银卡 → 用户可能已经感知到等级变化
3. 历史偏好明确：生椰拿铁50% → 召回应从老味道入手
4. 周四下午16:00，位置在家 → 可能是周末前的放松时刻
5. 天气晴24°C → 适合喝冰饮

流失原因未知，可能是竞品、季节变化、或单纯忘记。
策略：
- 情感化召回，"好久不见"而非"你有一张券"
- 推荐用户历史最爱（生椰拿铁），唤醒味觉记忆
- 优惠力度要大：回归专属券（3.8折或免费一杯）
- 不催促，给用户空间
- 同时尝试了解流失原因（简短问卷）

置信度：55%（中低置信度）——流失原因不明，召回策略需要测试。
```

### Agent 结构化输出

---

**【意图识别结果】**

- **意图类型**：无法确定（流失召回场景）
- **置信度**：55%（中低置信度）
- **生命周期阶段**：预警/流失用户（45天未消费，远超历史5-7天周期）
- **关键判断依据**：
  1. 45天未消费，历史复购周期5-7天，偏离度540%
  2. 会员等级从金卡降级为银卡
  3. 近30天APP打开0次，社群消息已屏蔽
  4. 历史偏好明确（生椰拿铁50%），但当前意图无法判断
  5. 流失原因未知（竞品/季节/忘记/其他）

---

**【推荐策略】**

- **推荐产品**：生椰拿铁 大杯（用户历史最爱，占比50%）
- **推荐理由**：用"老味道"唤醒用户记忆，降低重新决策的成本。生椰拿铁是用户消费最多的产品，也是瑞幸的招牌爆款
- **优惠方案**：回归专属礼 - 3.8折券（7天有效），或免费一杯生椰拿铁（限回归首单）
- **触达渠道**：短信（APP推送已无效，用户30天未打开APP）+ 企业微信一对一消息
- **执行时机**：周四下午16:00（周五前，用户可能计划周末出行）
- **营销文案**：
  > 好久不见，孙浩。你最爱的生椰拿铁，这杯我请。7天内回归，免费一杯，随时等你。

---

**【执行建议】**

- **执行方式**：中置信度，建议人工审核文案和优惠力度后执行
- **操作步骤**：
  1. 发送短信，文案如上，附带一键回归链接
  2. 企业微信同步发送（如果未被删除好友）
  3. 用户点击链接后，直接进入生椰拿铁下单页，优惠券自动抵扣
  4. 下单成功后，推送"欢迎回来"消息，并推荐加入"回归专属福利群"
  5. 附带一个极简的流失原因调研（1个问题："最近没怎么来，是因为？A.忙 B.喝了别家 C.没遇到喜欢的 D.其他"）
- **后续跟进**：
  - 如果7天内未回归，再推送一次橙C美式（用户第二偏好）的召回
  - 如果14天仍未回归，降低触达频率，每月1次品牌内容触达
  - 如果成功回归，进入"成长用户"策略，前3单给予额外关怀

---

**【反思记录】**

- **关键假设**：用户流失不是因为对品牌不满，而是暂时忘记或被竞品吸引
- **可能改进点**：如果用户填写了流失原因，需针对性调整策略；如果免费一杯仍无法召回，说明流失原因较深，需人工介入
- **需收集的反馈数据**：短信是否打开、链接是否点击、是否下单、流失原因调研结果、回归后7天内是否复购

## 样例 05：深夜加班提神

### 用户输入
```
用户ID：U006（赵明）
时间：周五 22:15
天气：晴 18°C
位置：公司（加班中）
历史偏好：拿铁（45%）、美式（30%）、摩卡（15%）、其他（10%）
最近消费：今天 8:50 拿铁大杯
月消费频次：11杯（其中4杯是21:00后）
累计消费：1,500元
会员等级：金卡会员
配送订单占比：60%
```

### Agent 结构化输出

---

**【意图识别结果】**

- **意图类型**：提神刚需（深夜加班续命）
- **置信度**：88%（高置信度）
- **生命周期阶段**：成熟用户（金卡会员，月消费11杯）
- **关键判断依据**：
  1. 周五22:15仍在公司，典型加班场景
  2. 今天早晨已点一杯拿铁，这是第二杯
  3. 历史数据显示月均4杯深夜订单，有深夜喝咖啡的习惯
  4. 深夜订单偏好甜口（摩卡/焦糖玛奇朵占比高于白天）
  5. 配送订单占比60%，加班时大概率选择配送

---
