# 模拟用户画像集

> 本文件包含 10 个模拟用户画像，覆盖六大意图类型、四个生命周期阶段、多种典型场景。
> 用于测试 Agent 在不同用户群体下的推荐效果，也可作为 Dify 测试输入。

## 画像 01：通勤刚需型 — 王磊

### 基础信息
| 字段 | 值 |
|------|-----|
| 用户ID | U001 |
| 姓名 | 王磊 |

| 职业 | 互联网公司程序员 |
| 城市 | 上海 |
| 会员等级 | 黑金会员 |
| 累计消费 | 3,200元 |
| 月均消费 | 22杯 |
| 注册时长 | 14个月 |

### 偏好特征
- **固定订单**：美式大杯（85%），偶尔换拿铁大杯
- **固定时段**：工作日 8:30-9:00，到店自取
- **固定门店**：公司楼下瑞幸
- **口味偏好**：苦、清爽、低卡、高咖啡因
- **价格敏感度**：低（几乎不用券，直接会员价下单）
- **社交属性**：低（从不拼单，不分享）

### 行为数据
- 最近30天消费22杯，全部为工作日早晨
- 连续打卡记录：最长连续45天

### 典型场景

- 置信度：≥90%

- 推荐策略：老样子美式大杯，黑金会员价8.5折，一键复购，不打扰
