## 一、经典咖啡系列

### 1. 美式咖啡
- **价格**：中杯 13元 / 大杯 16元
- **口味标签**：苦、清爽、低卡、提神
- **咖啡因含量**：高（约200mg/大杯）
- **推荐场景**：工作日早晨、加班、提神刚需
- **用户画像**：高频用户、成熟用户、美式爱好者
- **搭配建议**：可搭配全麦贝果作为早餐
- **产品描述**：精选阿拉比卡咖啡豆，高温高压萃取，口感清爽纯粹，苦味明显，是咖啡爱好者的经典选择。零糖零脂，适合控卡人群。

### 2. 拿铁
- **价格**：中杯 16元 / 大杯 19元
- **口味标签**：奶香、顺滑、微苦、大众接受度高
- **咖啡因含量**：中高（约150mg/大杯）
- **推荐场景**：日常通勤、下午茶、社交分享
- **用户画像**：最广泛的用户群体，新用户首选
- **搭配建议**：可搭配提拉米苏、巧克力蛋糕
- **产品描述**：浓缩咖啡与蒸汽牛奶的完美融合，口感丝滑柔顺，奶香与咖啡香平衡。是瑞幸销量最高的经典产品，适合绝大多数咖啡消费者。

### 3. 卡布奇诺
- **价格**：中杯 16元 / 大杯 19元
- **口味标签**：奶泡丰富、咖啡味浓、口感层次多
- **咖啡因含量**：中高
- **推荐场景**：休闲时刻、慢慢品尝
- **用户画像**：追求口感层次的咖啡爱好者
- **产品描述**：等比例的浓缩咖啡、蒸汽牛奶和奶泡，口感丰富有层次。奶泡绵密，咖啡味比拿铁更突出，适合喜欢慢慢品尝的用户。

### 4. 摩卡
- **价格**：中杯 18元 / 大杯 21元
- **口味标签**：巧克力香、甜、丝滑
- **咖啡因含量**：中
- **推荐场景**：下午茶、放松享受、甜品爱好者
- **用户画像**：喜欢甜口的用户、女性用户偏多
- **搭配建议**：可搭配原味可颂
- **产品描述**：浓缩咖啡与巧克力酱的融合，加入蒸汽牛奶，口感丝滑香甜。巧克力的醇厚与咖啡的微苦完美平衡，是甜口咖啡爱好者的首选。

### 5. 浓缩咖啡（Espresso）
- **价格**：单份 12元 / 双份 15元
- **口味标签**：极苦、浓郁、提神效果最强
- **咖啡因含量**：极高
- **推荐场景**：极度困倦、快速提神
- **用户画像**：硬核咖啡爱好者、重度咖啡因需求者
- **产品描述**：高温高压萃取的浓缩咖啡精华，口感浓郁强烈，苦味突出。单份仅30ml，提神效果极强，适合需要快速提神的场景。

### 6. 焦糖玛奇朵
- **价格**：中杯 19元 / 大杯 22元
- **口味标签**：焦糖香、甜、层次丰富
- **咖啡因含量**：中
- **推荐场景**：下午茶、放松享受、社交分享

### 7. 燕麦拿铁
- **价格**：中杯 18元 / 大杯 21元
- **口味标签**：谷物香、清爽、植物基
- **咖啡因含量**：中高

### 8. 生椰拿铁

## 六、知识库使用说明

1. **检索方式**：Agent 通过用户意图和偏好，从知识库中检索匹配的产品信息
2. **更新频率**：建议每月更新一次，同步新品上市和价格调整
3. **补充信息**：可根据实际运营需求，补充门店信息、活动信息、供应链信息等
4. **向量索引**：建议使用 Dify 的高质量索引模式，确保检索准确率
