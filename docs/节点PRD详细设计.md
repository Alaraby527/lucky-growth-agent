# Lucky Growth Agent 节点 PRD 详细设计

> 本文档定义工作流中每个节点的输入、输出、完成条件、失败处理和约束规则。
> 参考 AI Agent 编排方法论：节点设计 = 数据约束 + 完成条件 + 失败处理。

---

## 节点总览

| 节点 | 类型 | 上游 | 下游 | 模型 |
|------|------|------|------|------|
| 参数提取器 | 模型推理型决策节点 | 开始 | 代码执行、知识检索 | deepseek-v4-flash |
| 代码执行 | 执行节点（用户画像查询） | 参数提取器 | 策略分析 | 无（Python） |
| 知识检索 | 执行节点（RAG） | 参数提取器 | 策略分析 | qwen3-embedding + qwen3-rerank |
| 策略分析 | 模型推理型决策节点 | 代码执行+知识检索 | 回复生成 | deepseek-v4-flash |
| 回复生成 | 执行节点（文案生成） | 策略分析 | 直接回复 | deepseek-v4-flash |

## 节点 1：参数提取器

### 基本信息
- **节点名称**：参数提取器
- **节点 ID**：1787340345150
- **节点类型**：模型推理型决策节点
- **触发条件**：收到用户消息（sys.query）

### 输入定义

| 字段 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| sys.query | String | 是 | 开始节点 | 用户原始输入文本 |

### 输出定义

| 字段 | 类型 | 枚举值/格式 | 说明 |
|------|------|-------------|------|
| user_id | String | U+三位数字（如 U001），未提及则为空字符串 | 用户标识 |
| scene_context | String | 自由文本，包含时间/天气/位置/社交状态 | 场景上下文 |
| user_info | String | 自由文本，包含口味偏好/消费习惯/会员等级/价格敏感度 | 用户自述信息 |

### 决策规则
1. 只提取用户**明确提到**的信息，不推测、不编造
2. user_id 匹配正则 `U\d{3}`，不匹配则输出空字符串
3. 未提及的字段输出空字符串，不输出"未知""无"等占位词
4. 三个字段互相独立，可部分提取成功

### 完成条件（结果型）
- 三个输出字段均已赋值（含空字符串）
- 输出为合法 JSON，字段类型正确

### 失败处理

| 失败类型 | 处理方式 |
|----------|----------|
| 模型超时（>10s） | 重试 2 次，间隔 1s；仍失败则三个字段均输出空字符串，继续下游 |
| 模型输出格式错误 | 用正则从原始文本中提取 user_id；其余字段置空 |
| 模型限流（429） | 等待 2s 重试 1 次；仍失败则降级为空字符串 |
| 用户输入为空 | 直接输出三个空字符串，不调用模型 |

### 埋点
- 参数提取成功率（三个字段中至少一个非空的比例）
- user_id 提取准确率
- 平均提取耗时

## 节点 2：代码执行（用户画像查询）

### 基本信息
- **节点名称**：用户画像查询
- **节点 ID**：1787340822861
- **节点类型**：执行节点（工具调用）
- **触发条件**：参数提取器执行完成

### 输入定义

| 字段 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| user_id | String | 是 | 参数提取器.user_id | 用户标识 |

### 输出定义

| 字段 | 类型 | 格式 | 说明 |
|------|------|------|------|
| profile_summary | String | "用户画像(U001): 王磊,黑金会员,..." | 用户画像摘要 |

### 决策规则
1. 内置 10 个模拟用户画像（U001-U010）
2. user_id 精确匹配，大小写不敏感
3. 未匹配到返回提示文本："未找到用户 {user_id} 的画像数据，该用户可能为新用户"
4. user_id 为空时返回："用户未提供ID，无画像数据"

### 完成条件（结果型）
- profile_summary 字段非空字符串

### 失败处理

| 失败类型 | 处理方式 |
|----------|----------|
| 代码执行异常 | 返回 "用户画像查询异常，请稍后重试"，记录错误日志 |
| user_id 为空 | 不报错，返回"用户未提供ID"提示 |
| 执行超时（>5s） | 返回"画像查询超时"，继续下游（策略分析可基于场景上下文推荐） |

### 埋点
- 查询命中率（匹配到画像的比例）
- 平均查询耗时
- 异常率

## 节点 3：知识检索

### 基本信息
- **节点名称**：瑞幸菜单知识库检索
- **节点 ID**：1787323156314
- **节点类型**：执行节点（RAG 检索）
- **触发条件**：参数提取器执行完成（与代码节点并行）

### 输入定义

| 字段 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| query | String | 是 | sys.query（用户原始消息） | 检索查询文本 |

### 输出定义

| 字段 | 类型 | 格式 | 说明 |
|------|------|------|------|
| result | Array[Object] | [{content: String, title: String, score: Number}] | 检索到的文档片段，Top 5 |

### 检索配置
- 检索模式：混合检索（向量+全文）
- Top K：5
- 相似度阈值：0.5
- Rerank：qwen3-rerank，Top 3

### 完成条件（结果型）
- 返回 result 数组（可为空数组）

### 失败处理

| 失败类型 | 处理方式 |
|----------|----------|
| 检索服务超时（>8s） | 返回空数组，策略分析节点基于用户画像和场景推荐，不依赖知识库 |
| 检索结果为空 | 正常返回空数组，策略分析提示"知识库中暂无相关产品信息" |
| Embedding/Rerank 服务异常 | 降级为纯全文检索；仍失败则返回空数组 |
| 知识库未索引 | 返回空数组，触发告警通知运营 |

### 埋点
- 检索命中率（非空结果比例）
- 平均检索耗时
- 平均相关度分数
- Rerank 前后结果对比

## 节点 4：策略分析（LLM #1）

### 基本信息
- **节点名称**：策略分析
- 节点 ID：llm
- **节点类型**：模型推理型决策节点
- **触发条件**：代码执行和知识检索均完成

### 输入定义

| 字段 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| user_id | String | 否 | 参数提取器.user_id | 用户标识 |
| scene_context | String | 否 | 参数提取器.scene_context | 场景上下文 |
| user_info | String | 否 | 参数提取器.user_info | 用户自述 |
| profile_summary | String | 否 | 代码执行.profile_summary | 用户画像 |
| knowledge_result | Array | 否 | 知识检索.result | 菜单知识库结果 |
| sys.query | String | 是 | 开始节点 | 用户原始消息 |

### 输出定义

输出为结构化文本，包含四个部分：

```
## 意图分析
- 意图类型：[提神刚需|社交分享|放松享受|尝鲜探索|性价比驱动|习惯复购]
- 置信度：[0-100]%
- 生命周期阶段：[新用户|成长用户|成熟用户|预警流失]
- 关键依据：[3-5条]

## 推荐策略
- 推荐产品：[产品名+规格]
- 推荐理由：[结合意图和偏好]
- 优惠方案：[会员价/满减/折扣券/免费/无优惠]
- 触达渠道：[APP推送|社群|短信|店内推荐]
- 文案要点：[核心信息]

## 执行建议
- 置信度等级：[高|中|低]
- 执行建议：[可自主执行|建议人工审核|需澄清信息]
- 风险提示：[潜在风险]

## 反思记录
- 关键假设：[决策依赖的假设]
- 改进点：[可优化方向]
```

### 决策规则
1. 意图类型必须从六大枚举值中选择，不得自创
2. 置信度 ≥80% 为高，50-80% 为中，<50% 为低
3. 优惠力度不得超过生命周期阶段上限（新用户1.8折/成长满减/成熟8.5-9折/流失免费一杯）
4. 产品推荐必须来自知识库；知识库为空时明确说明，不编造产品详情
5. 低置信度不输出确定性推荐，改为输出澄清问题

### 完成条件（结果型）
- 输出包含四个部分的标题
- 意图类型为合法枚举值
- 置信度为 0-100 的数值

### 失败处理

| 失败类型 | 处理方式 |
|----------|----------|
| 模型超时（>15s） | 重试 1 次；仍失败则回复生成节点收到"策略分析超时"，生成通用兜底回复 |
| 输出格式不符合规范 | 回复生成节点尝试解析关键信息；解析失败则生成兜底回复 |
| 模型限流 | 等待 3s 重试 1 次；仍失败则降级 |
| 知识库为空+用户画像为空 | 强制低置信度，输出澄清问题，不做推荐 |

### 埋点
- 意图识别准确率（与人工标注对比）
- 置信度校准度（高置信度中实际正确的比例）
- 平均分析耗时
- Token 消耗量

## 节点 5：回复生成（LLM #2）

### 基本信息
- **节点名称**：回复生成
- **节点 ID**：llm_reply_1787379563329
- **节点类型**：执行节点（文案生成）
- **触发条件**：策略分析完成

### 输入定义

| 字段 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| analysis_result | String | 是 | 策略分析.text | 策略分析的完整输出 |
| sys.query | String | 是 | 开始节点 | 用户原始消息 |

### 输出定义

| 字段 | 类型 | 格式 | 说明 |
|------|------|------|------|
| text | String | 自然语言回复，≤150字 | 用户可见的推荐文案 |

### 决策规则
1. 不展示意图识别、置信度、策略矩阵、反思记录等内部信息
2. 语气像懂咖啡的朋友，不用营销腔
3. 必须包含：推荐产品 + 个性化理由 + 行动引导
4. 低置信度场景：用提问引导用户说出偏好，给选项而非开放式问题
5. 不提及"知识库""策略分析""系统"等后台概念
6. 不使用 markdown 标题和编号列表

### 完成条件（结果型）
- text 非空
- 长度 ≤150 字
- 不包含内部分析关键词（"意图识别""置信度""策略矩阵"等）

### 失败处理

| 失败类型 | 处理方式 |
|----------|----------|
| 模型超时（>10s） | 重试 1 次；仍失败则输出兜底回复："抱歉，我暂时无法为你推荐，请稍后再试或告诉我你的口味偏好。" |
| 输出包含内部信息 | 后处理过滤：检测到关键词则重新生成 1 次；仍不合格则输出兜底回复 |
| 输出超长（>150字） | 截断到最后一个完整句号；不超过 150 字 |
| 策略分析输入异常 | 生成通用友好回复，引导用户描述需求 |

### 埋点
- 文案审核通过率（不含内部信息、长度合规的比例）
- 用户满意度（点赞/踩）
- 平均生成耗时
- Token 消耗量

## 异常分支总览

```
主线流程（一切顺利）：
开始 → 参数提取 → 代码执行+知识检索（并行）→ 策略分析 → 回复生成 → 直接回复

异常分支：
参数提取失败 → 空字段继续 → 策略分析基于有限信息推荐（低置信度）
画像查询失败 → 返回错误提示 → 策略分析基于场景推荐
知识库为空 → 策略分析明确说明 → 基于画像推荐
策略分析超时 → 兜底回复
回复生成超时/含内部信息 → 兜底回复
全链路异常 → "系统繁忙，请稍后再试" + 告警
```
