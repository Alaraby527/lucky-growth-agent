# 用户旅程地图（User Journey Map）

> 本文档描述瑞幸咖啡用户从"认知→首单→成长→成熟→预警→流失→召回"的完整生命周期旅程，
> 以及 Lucky Growth Agent 在每个阶段的介入点、策略和预期效果。

---

## 一、全生命周期旅程总览

```
认知期        首单期         成长期          成熟期         预警期        流失期        召回期
(0天)      (第1-3杯)     (第4-10杯)     (10杯+/月)    (频次下降)   (30天+未消费)  (回归)
  │           │             │              │             │            │            │
  ▼           ▼             ▼              ▼             ▼            ▼            ▼
广告/社交    首单特惠      品类拓展       习惯固化      信号识别     流失确认     情感召回
引流        低门槛体验    频次提升       客单提升      原因分析     止损策略     老味道唤醒
  │           │             │              │             │            │            │

                                    Agent 全程介入
                           (感知→决策→执行→反思 闭环)
```

## 二、分阶段旅程详解

### 阶段1：认知期（注册前 → 注册当天）

#### 用户状态
- 对瑞幸有初步认知（通过广告、朋友推荐、社交媒体）
- 尚未注册或刚注册，未消费
- 对产品不熟悉，决策门槛高

#### 用户行为
| 行为 | 触点 | 用户情绪 |
|------|------|----------|
| 看到朋友圈广告"新客首杯1.8折" | 微信广告 | 好奇、犹豫 |
| 下载APP/打开小程序 | APP/小程序 | 期待但迷茫 |
| 浏览菜单，看到几十款产品 | 菜单页 | 选择困难 |
| 注册账号 | 注册页 | 完成注册但未下单 |

#### 用户痛点
- 产品太多，不知道选什么
- 不确定自己会不会喜欢
- 担心正价买了不好喝浪费钱

#### Agent 介入策略

| 介入点 | Agent动作 | 具体策略 |
|--------|-----------|----------|
| 注册完成 | 新客欢迎 | 推送1.8折首单券，降低尝试门槛 |
| 浏览菜单 | 选择引导 | 展示"大多数人的第一杯"（拿铁/美式/生椰拿铁），提供口味偏好选择题 |
| 未下单离开 | 温和提醒 | 24小时后推送"首单券还在，3天有效"，不催促 |

#### 关键指标
- 注册→首单转化率：目标 ≥ 35%
- 首单平均决策时间：目标 ≤ 5分钟
- 首单产品分布：拿铁40%、生椰拿铁30%、美式20%、其他10%

---

### 阶段2：首单期（第1-3杯，注册后1-2周）

#### 用户状态
- 已完成首单，对产品有了初步体验
- 尚未形成固定习惯，容易流失
- 对品牌的认知停留在"喝过一次"

#### 用户行为
| 行为 | 触点 | 用户情绪 |
|------|------|----------|
| 使用1.8折券下单首杯 | 下单页 | 期待、小兴奋 |
| 到店取餐/收到外卖 | 门店/配送 | 满足或失望 |
| 喝完第一杯 | - | "还不错"或"一般" |
| 收到第二杯券推送 | APP推送 | 被提醒，可能再试 |
| 3天内下第二单 | APP | 开始建立认知 |

#### 用户痛点
- 首单体验不好就直接流失
- 不知道第二杯该试什么
- 正价购买意愿低（首单1.8折后有价格落差）

#### Agent 介入策略

| 介入点 | Agent动作 | 具体策略 |
|--------|-----------|----------|
| 首单完成后 | 正向反馈 | 推送"好喝吗？"评价邀请，根据评价推荐第二杯 |
| 首单好评 | 同系列推荐 | "喜欢拿铁？试试丝绒拿铁，口感更丝滑"，第二杯立减5元 |
| 首单中评/差评 | 补救+换品类 | "没喝到心仪的？这杯生椰拿铁很多人喜欢，3.8折再试一次" |
| 第3天下单 | 习惯引导 | 连续3天下单送第4杯免费，开始培养频次 |
| 首单后7天未复购 | 二次唤醒 | 推送"想你了"3.8折券，推荐与首单不同品类的产品 |

#### 关键指标
- 首单→3单转化率：目标 ≥ 50%
- 首周消费杯数：目标 ≥ 2杯
- 首单好评率：目标 ≥ 80%
- 7天未复购率：目标 ≤ 30%

---

### 阶段3：成长期（第4-10杯，注册后1-3个月）

#### 用户状态
- 已形成初步消费习惯（月均3-8杯）
- 有1-2款常喝产品，但愿意尝试新品
- 开始关注优惠活动，会用券
- 部分用户开始拼单、加入社群

#### 用户行为
| 行为 | 触点 | 用户情绪 |
|------|------|----------|
| 每周固定点2-3次 | APP | 习惯成自然 |
| 尝试新品/特调 | 菜单页/推荐 | 好奇、新鲜感 |
| 和同事拼单 | 企业微信社群 | 社交乐趣 |
| 参与连续打卡活动 | 活动页 | 被激励 |
| 升级银卡/金卡 | 会员页 | 成就感 |

#### 用户痛点
- 喝久了想换口味但不知道换什么
- 优惠信息太多，分不清哪个最划算
- 拼单流程不够顺畅

#### Agent 介入策略

| 介入点 | Agent动作 | 具体策略 |
|--------|-----------|----------|
| 识别到口味固化 | 品类拓展 | "最近喝了5杯美式，要不要试试橙C美式？清爽果味，第二杯半价" |
| 下午茶时段 | 社交引导 | 推送拼单优惠"拉上同事，第二杯半价"，促进社交裂变 |
| 连续消费 | 频次激励 | 连续打卡7天送免费一杯，培养每日习惯 |
| 新品上市 | 精准推荐 | 根据用户口味偏好推荐新品（如偏好甜口→推荐小黄油拿铁） |
| 轻食交叉销售 | 客单提升 | "搭配全麦贝果，早餐立减5元"，提升客单价 |
| 会员升级 | 成就激励 | "再消费2杯升级金卡，享9折优惠"，推动升级 |

#### 关键指标
- 成长期→成熟期转化率：目标 ≥ 40%
- 月均消费杯数：目标从3杯提升到8杯
- 品类拓展率（尝试3款以上产品）：目标 ≥ 60%
- 拼单参与率：目标 ≥ 35%
- 客单价提升：目标 +15%

---

### 阶段4：成熟期（月均10杯+，注册3个月+）

#### 用户状态
- 消费习惯稳固（月均10杯+）
- 有明确的产品偏好和固定消费时段
- 对品牌有忠诚度，是核心用户
- 部分用户成为KOC，主动分享和推荐

#### 用户行为
| 行为 | 触点 | 用户情绪 |
|------|------|----------|
| 工作日固定时段下单 | APP/一键复购 | 自动化、不犹豫 |
| 尝试高端线/季节限定 | 菜单页 | 品质追求 |
| 购买周边/囤券 | 商城 | 品牌认同 |
| 在社群分享体验 | 企业微信 | 归属感 |
| 参与新品内测 | 内测邀请 | 被重视感 |

#### 用户痛点
- 固定习惯后容易无聊
- 大额优惠对他们刺激不大（本来就会买）
- 希望获得"专属感"和"被重视"

#### Agent 介入策略

| 介入点 | Agent动作 | 具体策略 |
|--------|-----------|----------|
| 固定时段消费 | 一键复购 | "老样子已备好"提前推送，到店即取，极致便捷 |
| 品质升级 | 高端推荐 | 推荐丝绒拿铁/手冲等高端线，黑金会员专属价 |
| KOC识别 | 共创邀请 | 邀请参与新品内测、口味投票、品牌活动 |
| 会员权益 | 专属感 | 黑金会员8.5折、免费升杯、生日双倍积分 |
| 长效忠诚 | 情感连接 | 周年纪念"你已经喝了365杯瑞幸"、年度咖啡报告 |
| 周边/囤券 | LTV提升 | 自由卡推荐、周边新品优先购、节日礼盒 |

#### 关键指标
- 成熟期用户留存率：目标 ≥ 90%/月
- 月均消费杯数：目标 ≥ 12杯
- 客单价：目标 ≥ 20元
- KOC转化率：目标 ≥ 10%（成熟用户中成为KOC的比例）
- NPS（净推荐值）：目标 ≥ 50

---

### 阶段5：预警期（频次下降，尚未完全流失）

#### 用户状态
- 消费频次开始下降（较历史均值下降30%+）
- 可能在尝试竞品、或生活节奏变化
- 尚未完全离开，仍有挽回机会
- 这是最关键的干预窗口

#### 预警信号识别

| 信号类型 | 具体指标 | 预警等级 |
|----------|----------|----------|
| 频次下降 | 周消费杯数较4周均值下降30%+ | 黄色预警 |
| 间隔拉长 | 距上次消费超过历史复购周期2倍 | 橙色预警 |
| 互动下降 | APP打开频率下降50%+ | 黄色预警 |
| 优惠依赖 | 无券不下单，券核销率100% | 黄色预警 |
| 投诉/差评 | 近期有投诉或差评记录 | 橙色预警 |
| 社群屏蔽 | 退出社群或屏蔽消息 | 红色预警 |

#### Agent 介入策略

| 预警等级 | Agent动作 | 具体策略 |
|----------|-----------|----------|
| 黄色预警 | 轻度干预 | 推送用户最爱的产品优惠，"好久没喝美式了，今天会员价" |
| 橙色预警 | 中度干预 | 推送个性化召回券（3.8折），附"我们想你了"情感文案 |
| 红色预警 | 强力干预 | 免费一杯券+人工关怀（企业微信一对一消息），了解原因 |

#### 关键指标
- 预警识别准确率：目标 ≥ 80%
- 预警期→回归正常比例：目标 ≥ 45%
- 预警→流失转化率：目标 ≤ 30%
- 平均干预响应时间：目标 ≤ 24小时

---

### 阶段6：流失期（30天+未消费）

#### 用户状态
- 已30天以上未消费
- APP可能已卸载或不再打开
- 社群消息可能已屏蔽
- 流失原因多样：竞品、口味变化、生活变化、不满体验

#### 流失原因分类

| 流失原因 | 占比（估） | 特征 | 召回难度 |
|----------|-----------|------|----------|
| 竞品转移 | 30% | 开始消费Manner/星巴克等 | 中 |
| 口味疲劳 | 25% | 长期喝同几款，想换口味 | 低 |
| 生活变化 | 20% | 搬家/换工作/怀孕/健康原因 | 高 |
| 价格敏感 | 15% | 觉得正价贵，等大促 | 低 |
| 体验不满 | 10% | 遇到品质问题或服务问题 | 中 |

#### Agent 介入策略

| 流失原因 | 召回策略 | 优惠力度 | 文案风格 |
|----------|----------|----------|----------|
| 竞品转移 | 差异化推荐（瑞幸独有产品如生椰拿铁） | 3.8折 | "还是这个味道" |
| 口味疲劳 | 推荐新品/季节限定 | 免费一杯新品 | "上新了，试试？" |
| 生活变化 | 低频关怀，不催促 | 生日/节日券 | 温暖、不打扰 |
| 价格敏感 | 大额券+囤券包 | 1.8折回归券 | 直接、划算 |
| 体验不满 | 道歉+补偿+品质承诺 | 免费一杯+客服跟进 | 真诚、改进 |

#### 关键指标
- 流失用户召回率：目标 ≥ 20%
- 召回后30天留存率：目标 ≥ 40%
- 召回成本：目标 ≤ 15元/人
- 流失原因调研回收率：目标 ≥ 15%

---

### 阶段7：召回期（回归后1个月）

#### 用户状态
- 被成功召回，重新下单
- 但忠诚度不稳定，容易再次流失
- 需要特殊关怀，重新建立习惯

#### Agent 介入策略

| 时间点 | Agent动作 | 具体策略 |
|--------|-----------|----------|
| 回归首单 | 欢迎回来 | "欢迎回来"消息+回归专属权益 |
| 回归后3天 | 二次巩固 | 推荐与回归首单不同的产品，"再试试这个？"第二杯立减 |
| 回归后7天 | 习惯重建 | 连续打卡活动，7天内3杯送免费一杯 |
| 回归后14天 | 社群重连 | 邀请重新加入社群，参与活动 |
| 回归后30天 | 状态评估 | 评估是否恢复到流失前频次，决定是否退出"特殊关怀"模式 |

#### 关键指标
- 召回→30天留存率：目标 ≥ 40%
- 召回后首月月均杯数：目标 ≥ 4杯
- 二次流失率：目标 ≤ 40%

## 四、关键用户故事（User Stories）

### 故事1：李思雨的下午茶社交旅程

> 李思雨是新媒体运营，周三下午15:00在公司群问"有人喝瑞幸吗？"
>
> Agent感知到：周三下午+公司位置+历史拼单行为+社群活跃 → 意图：社交分享，置信度85%
>
> Agent决策：推荐生椰拿铁（她的最爱）+第二杯半价+轻食搭配
>
> Agent执行：APP推送"下午茶时间到，生椰拿铁第二杯半价，拉上同事一起？"
>
> 李思雨点击推送，选择3杯生椰拿铁+2个提拉米苏，使用第二杯半价，下单成功。
>
> Agent反思：本次拼单转化率高，记录"周三下午+公司"为高转化场景，下周同一时段提前推送。

### 故事2：孙浩的流失与召回

> 孙浩曾是金卡会员，月均6杯，但45天前突然停止消费。
>
> Agent在第14天识别到黄色预警（频次下降），推送"好久没喝生椰拿铁了，今天会员价"——未响应。
> 第21天升级橙色预警，推送3.8折召回券——未响应。
> 第35天确认流失，Agent分析：最后一杯是生椰拿铁，历史偏好50%，流失原因可能是口味疲劳或竞品。
>
> Agent决策：推荐新品+免费一杯，短信文案"好久不见，孙浩。你最爱的生椰拿铁，这杯我请。"
>
> 孙浩收到短信，点击链接，发现瑞幸出了秋季新品桂花酒酿拿铁，免费一杯下单尝试。
>
> 回归后Agent进入"特殊关怀"模式，7天内推荐了3款他没试过的产品，孙浩重新开始每周3杯的消费。

### 故事3：王磊的极致效率旅程

> 王磊是程序员，每个工作日8:50固定点美式大杯。
>
> Agent在8:30（他出门时）推送："周一早，老样子？大杯美式已备好，到店即取。"
>
> 王磊点击"一键下单"，无需选品，8:45到店直接取走，全程不超过10秒。
>
> 某天王磊8:45还没下单，Agent在8:50推送温和提醒："老样子还在等你，今天要换一杯吗？"
>
> 周五王磊加班到22:00，Agent感知到深夜+公司位置，推送"周五深夜还在忙？这杯摩卡陪你搞定最后一个PPT。"
>
> Agent反思：王磊的习惯极其稳定，不需要复杂推荐，核心是"快"和"不打扰"。

## 五、旅程优化机会点

| 机会点 | 当前痛点 | Agent优化方案 | 预期提升 |
|--------|----------|---------------|----------|
| 新客决策 | 产品太多选择困难 | 口味偏好选择题+3个经典选项 | 首单转化率+10pp |
| 首单后流失 | 首单体验不好就走 | 评价跟进+差评补救+换品推荐 | 3单转化率+15pp |
| 口味固化 | 长期喝同款易疲劳 | 智能品类拓展推荐 | 品类拓展率+20pp |
| 预警滞后 | 等流失了才干预 | 实时信号监测+分级预警 | 召回率+25pp |
| 召回同质化 | 所有流失用户发同样券 | 基于流失原因的差异化策略 | 召回率+15pp |
| 成熟用户无聊 | 固定习惯缺乏新鲜感 | KOC共创+季节限定+年度报告 | NPS+10分 |
